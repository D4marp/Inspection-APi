LOCAL TRAINING CONTENT

Migrasi Kotlin → Flutter

WebView dipakai sebagai bounded surface, bukan jalan pintas untuk memindahkan seluruh aplikasi.

1. Trace perilaku lama

  • Baca Activity/Fragment, XML, ViewModel, Retrofit, dan storage yang relevan.
  • Catat input, output, state, navigation, error, dan side effect.
  • Jangan menebak contract dari nama class.

2. Tulis PRD slice

  1. Definisikan user outcome dan batas scope.
  2. Turunkan acceptance criteria yang dapat diuji.
  3. Petakan setiap AC ke bukti: test, screenshot, log, atau review.

3. Implementasikan Flutter

Screen → Controller → Repository → ApiClient

Pertahankan contract. Migrasikan satu vertical slice sampai selesai sebelum membuka slice berikutnya.

WebView security baseline

  • Allowlist origin dan navigation.
  • Matikan JavaScript bila tidak dibutuhkan.
  • Jangan menaruh provider API key di HTML, JavaScript, atau bundle Flutter.
  • Definisikan back behavior, loading, error, session, dan logout.
